# 📱 Installable PWA

**Status:** ⬜ Pending · **Priority:** Medium · **Effort:** M (1-3 days) · **Dependencies:** None

## Why
The product decision is "installable PWA with an offline shell", and the primary usage is mobile: logging an expense from the phone in the moment. Today there's no `manifest` or service worker, so it can't be installed or opened without the browser chrome. It's the difference between "a website" and "an app" for the end user.

## Scope
**Includes:**
- Web app manifest with name, icons and theme colors
- Service worker with precache of the shell (HTML/JS/CSS/assets)
- App icons (192/512, maskable) generated from the Wallet logo
- `apple-touch-icon` and meta tags for iOS

**Doesn't include:**
- Caching API data (`/api` calls are online-first, they are NOT cached)
- Offline queue for transactions to sync later (future phase)
- Push notifications

## Proposed design

### Backend
- No changes

### Frontend
- Add `vite-plugin-pwa` to the React+Vite+TS app
- Manifest: name "Family Finances", `short_name`, `display: standalone`, `start_url: /`, `background_color` and `theme_color` synced with the app's dark mode (check how the theme is currently defined to avoid duplicating the color)
- Icons: generate 192x192 and 512x512 (including a `maskable` variant with safe padding) from the existing Wallet logo; add an `apple-touch-icon` (180x180) in `index.html`
- Service worker: precache the shell (build assets); **network-only/online-first strategy for `/api/*`** — if the network fails, the UI shows an error message, not stale cached data
- Register the SW and handle updates (prompt or auto-update; to be decided, preferably auto-update with a silent reload for a family app)

### Infra
- Verify that nginx (frontend) serves the `manifest.webmanifest` and the SW with the correct headers (the SW must be served with `Cache-Control: no-cache` so updates land)
- Confirm that the frontend's Docker build includes the files generated by `vite-plugin-pwa`

## Acceptance criteria
- [ ] On Android/Chrome the install prompt appears and the app installs with its own icon
- [ ] On iOS you can "Add to Home Screen" with the correct icon
- [ ] The installed app opens in standalone mode (no browser bar)
- [ ] Offline, the shell loads (UI visible) even if data fails with a clear message
- [ ] Calls to `/api` never return stale cached data
- [ ] The Lighthouse PWA check passes

## Notes
- HTTPS: SWs require a secure context; on self-hosted by IP+HTTP, installation may not be available. Document that HTTPS is recommended (reverse proxy / Tailscale / etc.).
- Risk: a poorly configured SW can leave clients "stuck" on an old version of the frontend. Test the update flow before considering this closed.
- Reference: https://vite-pwa-org.netlify.app/
